# ARCHMIND — Architectural AI Workspace

See [`README-WEB.md`](README-WEB.md) for Arabic and English instructions to run the free edition locally or publish it on Render.

This package includes 200 architectural prompts with visual references, the 15-stage workflow, Arabic/English interface, AI file attachments, and the 44-page non-commercial reference-book gallery. There is no payment or checkout flow. Daily free credits are rate-limited to protect the AI provider account used by the site owner.

Keep API keys and Gmail App Passwords in server environment settings. Never commit `.env`, user accounts, or project data. The Render blueprint mounts persistent storage at `/var/data`.
